## 匿名提问箱 Q&Asys — 方案定稿（尚未开工）

**需求**：匿名提问箱，Serverless，部署 Vercel，前端设计要强。

**已拍板**
- 视觉方向：B「午夜电台」—— 近黑底 + 荧光青柠强调色 + 大字排版。设计概念拟定为「深夜频率」：频率刻度、ON AIR 指示灯、问题像节目曲目编号、回答像主播口播。
- 使用范围：单主人、单箱，一个公开链接。
- 后台登录：GitHub OAuth（Auth.js v5，JWT session，用环境变量白名单限制 GitHub login）。
- 功能：只做「先审后发」。不做点赞、邮件提醒、图片附件。

**技术选型**
- Next.js 15 App Router + TypeScript + Tailwind v4 + motion
- Neon Postgres + Drizzle ORM（Vercel 集成市场接入）
- 反滥用：蜜罐字段 + ip_hash 限流（不存明文 IP）+ 长度限制
- 路由：`/` 公开提问箱、`/q/[id]` 单条问答分享页（OG 图）、`/admin` 后台
- 数据表：`boxes`（id/slug/title/intro/theme/is_open/owner_login）、`questions`（id/box_id/body/nickname/is_anon/status/answer/answered_at/ip_hash/created_at）
- status 枚举：pending / published / answered / hidden

## 已交付：拾光信箱 v0.1

**栈**：Next.js 15.5.29（App Router）+ React 19.1.0 + Tailwind v4 + 原生 neon 驱动 + jose。bun 1.3.14 管理依赖。

**关键文件**
- `src/app/globals.css`：设计 token（paper #f6f1e6 / ink #1c1917 / seal #b23a2c / rule #d9ceb8），纸纤维噪点 `.grain`、信纸横格 `.ruled`（行高 34px）、盖章动画 `.stamp-in`
- `src/components/compose-card.tsx`：首页提问卡，`onSubmit` + `useTransition` 显式调用 server action（**不用 useActionState**）
- `src/lib/actions.ts`：只放公开动作 `submitQuestion`
- `src/lib/admin-actions.ts`：后台动作（回信/公开/收起/登出），与上面必须分开
- `src/lib/store/`：`index.ts` 按 `DATABASE_URL` 分发到 `neon-store.ts` 或 `local-store.ts`（`.data/db.json`，首次自动 seed）
- `src/lib/auth.ts`：`isDevOpen()` = 非 production 且无 AUTH_GITHUB_ID 时免登录
- `db/schema.sql`：单表建表语句

**踩坑记录（重要）**
1. Next 15.5 构建期报 `TypeError: Cannot convert object to primitive value`，根因是 `"use server"` 模块**同时**导出被客户端引用的动作和带 `next/navigation`/auth 依赖的后台动作。拆分文件即解决。排查花了不少时间，下次直接从拆分入手。
2. React 19.3 + Next 15.5 存在兼容隐患，已锁 `react@19.1.0` / `react-dom@19.1.0`（精确版本，非 ^）。
3. Tailwind v4 里 `h-[calc(100dvh-3.5rem)]` 无效，必须写 `calc(100dvh_-_3.5rem)`。
4. 自定义 class 不能直接配变体（`focus-within:sheet-shadow-lift` 无效），要在 globals.css 里写 `.x:focus-within`。
5. 截图验证要小心：`chrome --window-size` 不会真的改布局视口，必须用 CDP `Emulation.setDeviceMetricsOverride`，否则会误判成横向溢出。

**验证过的链路**
- 首页投递 → 写入 pending → 印章动画 ✓
- 后台回信并公开 → `revalidatePath("/")` → 首页立刻出现，计数 5→6 ✓
- 390 / 1440 视口无横向溢出（scrollWidth == innerWidth）✓
- `bun run typecheck` 与 `bunx next build` 均通过
