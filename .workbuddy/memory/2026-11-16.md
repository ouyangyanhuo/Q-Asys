## 后台回函

- 根因：`<AdminReplyBox id={active.id} …/>` 无 `key`，内部 `useState(defaultAnswer)` 只在挂载时初始化 → 切信不回填。

## 详情页拆分为 ISR + 私函路由（速度）

- 关键发现：`/q/[id]` 虽写了 `revalidate = 60`，但**动态段没有 `generateStaticParams` 时 App Router 按纯动态处理**，响应头 `private, no-store`，CDN 完全不缓存 —— 每个访客都要跑函数。
- 修法：加 `export async function generateStaticParams() { return [] }`，构建输出从 `ƒ` 变 `●`，实测首访 MISS、二次 `x-nextjs-cache: HIT`，`s-maxage=60`。
- 拆路由：`/q/[id]` 只渲染 published（ISR）；新增 `/p/[id]` 动态校验 cookie 后渲染 pending（本人可见）。
- 排版抽到 `src/components/letter-view.tsx`（`owned` 控制提示条），两条路由共用。
- 列表里候复私函的正文链接改指向 `/p/<id>`；`admin-actions` 改稿/公开/收起后 `revalidatePath('/q/<id>')`。
- 实测：`/q/<pending>` 404、`/p/<pending>` 无 cookie 404、本人 200 且有提示条；列表首卡 href 为 `/p/...`。
